# Brian Gasto Mrema - Portfolio Website

Professional portfolio website built with Django CMS.

## Features
- Fully controlled via Django Admin Panel
- Dark/Light mode toggle
- Responsive design
- Contact form
- Blog system
- Project showcase

## Tech Stack
- Django 5.x
- Python 3.13
- Tailwind CSS
- JavaScript (Particles.js, AOS)
- SQLite (development)
